# PagoVoz · actualizaciones

Este repositorio lo escribe automáticamente el proceso de publicación de PagoVoz. **No lo edites a mano.**

- `latest.json`: aviso de la última versión, **firmado** (Ed25519). Cada instalación comprueba la firma con la llave pública que lleva la app y rechaza todo lo que no coincida.
- `files/`: paquetes de cada versión y de las librerías.
